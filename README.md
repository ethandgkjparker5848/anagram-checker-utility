## Overview

Anagram Checker provides a small, browser-based way to compare two pieces of text. Supply a pair of words or phrases, and the application analyzes their letters to determine whether one can be rearranged into the other.

It is useful for puzzle solving, word games, language practice, and fast text comparisons. Since the utility is delivered as HTML, a compatible browser is enough to run it; no separate desktop installation is required.
